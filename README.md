## 🚀 Что нового в версии 1.3.1:
- **Устранение рассинхронизации воспроизведения и паузы (Play/Pause Oscillation Fix)**: Полностью решена проблема заикания («кваканья») при ручном возобновлении трека или после завершения стороннего медиа (например, видео в Telegram/Instagram). Теперь вызов воспроизведения/паузы управляется напрямую через внутренний Web Playback API без конфликтующих синтетических нажатий на кнопку плеера.
- **Мгновенное автоматическое возобновление**: Трек безошибочно продолжает играть после освобождения аудиофокуса сторонними приложениями.
- **Плавное ручное управление**: Кнопка воспроизведения на мини-плеере, в шторке уведомлений и на главном экране срабатывает с первого нажатия без ложных остановок.

## ✨ Основные возможности
- Удобный интерфейс Spotify, оптимизированный под мобильные экраны.
- Нативная нижняя панель навигации (Главная, Поиск, Моя медиатека).
- Полноэкранный плеер, мини-плеер и таймер сна (Sleep Timer).
- Фоновое воспроизведение и управление через системную шторку (MediaSession / Lock Screen / Bluetooth).
- Улучшенный поиск с быстрым сбросом и закрытием истории запросов.

## 📱 Инструкция по установке
1. Перейдите во вкладку [Releases](https://github.com/P0m1dOr/spotify-clone-releases/releases).
2. Скачайте файл **spotify-clone-v1.3.1.apk**.
3. Откройте скачанный файл на вашем смартфоне и нажмите **«Установить»** (или **«Обновить»**, если приложение уже установлено).
4. Если Google Play Защита (Play Protect) предложит проверить приложение — нажмите **«Проверить»** («Scan»). Проверка подтвердит безопасность и приложение успешно установится.
