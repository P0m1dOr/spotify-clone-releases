# Spotify Clone for Android (Releases)

Публичный репозиторий официальных релизов мобильного приложения Spotify Clone для Android.

## 📥 Скачать актуальную версию

Актуальная сборка всегда доступна в разделе **[Releases](https://github.com/P0m1dOr/spotify-clone-releases/releases)**.

- **Версия:** [v1.2.0](https://github.com/P0m1dOr/spotify-clone-releases/releases/tag/v1.2.0)
- **Файл:** [spotify-clone-v1.2.0.apk](https://github.com/P0m1dOr/spotify-clone-releases/releases/download/v1.2.0/spotify-clone-v1.2.0.apk) (или в папке [`apk/spotify-clone-v1.2.0.apk`](apk/spotify-clone-v1.2.0.apk))

## 🚀 Что нового в версии 1.2.0:
- **Медиатека («Любимые треки»)**: Мгновенный переход к списку любимых треков пользователя при нажатии на вкладку «Медиатека».
- **Добавление в плейлист**: Новое модальное окно добавления трека в любой существующий или новый плейлист (вызывается кнопкой «+» на мини-плеере и экране Now Playing).
- **Быстрый лайк в строке трека**: Переключение добавления/удаления трека в «Любимые» прямо из строки трека.
- **Персональные плейлисты**: Автоматический сбор и отображение личных плейлистов текущего авторизованного пользователя из веб-интерфейса (полная изоляция от тестовых профилей).
- **Официальная подпись APK**: Сборка подписана сертификатом со схемами v2 и v3, обеспечивая корректную и безопасную установку через Google Play Protect.

## ✨ Основные возможности
- Удобный интерфейс Spotify, оптимизированный под мобильные экраны.
- Нативная нижняя панель навигации (Главная, Поиск, Моя медиатека).
- Полноэкранный плеер, мини-плеер и таймер сна (Sleep Timer).
- Фоновое воспроизведение и управление через системную шторку (MediaSession / Lock Screen / Bluetooth).
- Улучшенный поиск с быстрым сбросом и закрытием истории запросов.

## 📱 Инструкция по установке
1. Перейдите во вкладку [Releases](https://github.com/P0m1dOr/spotify-clone-releases/releases).
2. Скачайте файл **spotify-clone-v1.2.0.apk**.
3. Откройте скачанный файл на вашем смартфоне и нажмите **«Установить»** (или **«Обновить»**, если приложение уже установлено).
4. Если Google Play Защита (Play Protect) предложит проверить приложение — нажмите **«Проверить»** («Scan»). Проверка подтвердит безопасность и приложение успешно установится.
